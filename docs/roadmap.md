# 기능 로드맵

## 기획 방향

**sevin.dev 블로그는 개인 기술 블로그다.**
- 작성자(ADMIN) 1명, 독자는 로그인 불필요
- 티스토리/네이버 블로그처럼 회원가입을 요구하지 않음
- 독자 참여는 익명 기반(댓글, 반응)으로 충분
- 개발 경험/지식 공유가 주 목적

---

## Phase 1 — 핵심 (MVP)

> 블로그의 최소 기능. 이것 없으면 블로그가 아님.

| 기능 | 설명 |
|---|---|
| 인증 (JWT) | ADMIN 로그인/로그아웃, HttpOnly Cookie |
| 게시글 CRUD | Markdown 작성, 상태 관리, Soft Delete |
| 태그 / 카테고리 | 게시글 분류 |
| 익명 댓글 | nickname + password, bcrypt 저장 |
| 게시글 목록 / 상세 | slug 기반, cursor 페이지네이션 |
| 제목+내용 검색 | PostgreSQL Full-text |
| Health Check | 운영 모니터링 |

---

## Phase 2 — 콘텐츠 강화

> 블로그다운 경험을 위한 기능.

| 기능 | 설명 | 이유 |
|---|---|---|
| 시리즈(Series) | 순서 있는 글 묶음, 이전/다음 네비게이션 | 기술 블로그는 연재 글이 많음. 카테고리와 다르게 "편수"와 순서가 있음 |
| 예약 발행 | scheduledAt 기반 자동 PUBLISHED 전이 | 글을 미리 써두고 원하는 시간에 발행 |
| 이미지 업로드 | S3, 10MB, png/jpg/jpeg/gif | 마크다운에 이미지 삽입 |
| 관련 글 추천 | 같은 태그/카테고리 글 3개 | 독자 체류 시간 향상 |
| 독서 시간 표시 | 단어 수 기반 예상 시간 (분) | 글 읽기 전 시간 가늠 |
| 조회수(viewCount) | post_stats 테이블, 게시글 상세에 표시 | 인기 글 파악 |

---

## Phase 3 — 독자 인게이지먼트

> 독자가 로그인 없이 참여할 수 있는 기능.

| 기능 | 설명 | 이유 |
|---|---|---|
| 반응(Reaction) | 👍 ❤️ 🔥 🤔 토글, anonId 중복 방지 | 댓글보다 부담 없는 피드백. 로그인 불필요 |
| 이메일 구독 | 이메일만 입력, 새 글 발행 시 알림 | 독자가 재방문 없이 새 글을 받아볼 수 있음. 로그인 불필요 |
| RSS 피드 | `/feed.xml` 제공 | RSS 리더 사용자 지원 |
| 게시글 공유 OG | title/description/thumbnail OG 태그 | SNS 공유 시 미리보기 품질 향상 |

---

## Phase 4 — 운영 / SEO

> 혼자 운영하면서 편의성과 가시성을 높이는 기능.

| 기능 | 설명 | 이유 |
|---|---|---|
| Analytics 대시보드 | PV/UV/DAU/MAU, 게시글별 조회수, 유입 경로 | 어떤 글이 잘 읽히는지 파악 |
| Sitemap 자동 갱신 | 글 발행 시 sitemap.xml 재생성 | 검색 엔진 인덱싱 속도 향상 |
| 관리자 에디터 | Markdown 에디터, Preview, 자동저장 | 글쓰기 UX (FE 영역) |
| 글 고정(Pin) | 목록 상단 고정 | 중요 글 강조 |
| 금칙어 필터 | 댓글 작성 시 필터링 | 스팸 방지 |

---

## 보류 / 고민 중

| 기능 | 이유 |
|---|---|
| 대댓글(nested comment) | 개인 블로그 규모에서 구현 복잡도 대비 효용이 낮음. 단일 레벨로 충분 |
| 독자 회원가입 | 개인 블로그 정체성과 맞지 않음. 익명 참여로 대체 |
| 좋아요(소셜 로그인 기반) | 마찬가지로 로그인 요구 불필요. Reaction으로 대체 |
| 다국어(i18n) | 한국어 단일로 충분 |
| 전문 검색엔진(Elasticsearch) | PostgreSQL Full-text로 개인 블로그 트래픽 대응 가능 |

---

## 개발 순서 권장

```
Phase 1 (MVP) → Phase 2 (시리즈, 예약 발행, 이미지) → Phase 3 (반응, 구독) → Phase 4 (Analytics, SEO)
```

Phase 1만 완성해도 실제 운영 가능한 블로그가 됨.
